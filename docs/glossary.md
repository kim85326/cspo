# 共同語言（Glossary）

PO、測試、工程三方都用這份表上的詞。程式裡的名字對應右欄，看 code 時可以對照。

| 名詞 | 定義 | 程式裡的名字 |
|---|---|---|
| 股票代號 | 台股 4 到 6 碼數字，例如 2330 | `symbol` |
| 股票名稱 | 公司或 ETF 的簡稱，例如 台積電 | `name` |
| 股票清單 | 可以選的股票（代號 + 名稱）。app 裡是證交所全市場（當天有成交的上市股票與 ETF，約 1,300 多檔），熱門 40 檔排最前面；測試用固定 40 檔 | `StockDirectory` |
| 買入價 | 每股買進價格 | `buyPrice` |
| 數量 | 股數。1 張 = 1000 股。第一版以「股」為單位 | `shares` |
| 現價 | 最近一筆成交價或收盤價 | `currentPrice` / `Quote.price` |
| 持股 | 一筆「代號 + 買入價 + 數量」的紀錄 | `Holding` |
| 買入成本 | 買入價 × 數量 | `cost` |
| 現值 | 現價 × 數量 | `marketValue` |
| 盈虧 | 現值 − 買入成本 | `pnl` |
| 報酬率 | 盈虧 ÷ 買入成本 | `returnRate` |
| 行情來源 | 給代號回現價的地方。app 裡接證交所 OpenAPI 的「每日收盤行情」（前一個交易日收盤價，交易日 15:00 後更新，一次拿全市場，5 分鐘內不重抓）；自動化測試與 `EXPO_PUBLIC_USE_FAKE_PRICES=1` 時用固定假價 | `PriceSource`（`twseSource` / `fakePriceSource`） |
| 資料日期 | 現價是哪一個交易日的收盤價，結果卡上顯示「收盤價 2026/10/22」。假價沒有這欄 | `Quote.asOf` |
| 行情載入失敗 | 斷網或證交所沒回應，畫面顯示「行情載入失敗，請檢查網路後重試」，再按「計算」會重試 | `PriceLoadError` |

## 顯示慣例

- 台股漲紅跌綠，跟美股相反。
- 盈虧金額顯示到整數，千分位逗號，正數帶 `+`。
- 報酬率顯示兩位小數百分比。

## 第一迭代刻意不做

- 手續費（0.1425%，最低 20 元）與交易稅（0.3%）。
- 多筆持股與總盈虧。
- 把持股存起來。

## 假價表（自動化測試用）

自動化測試用 `src/data/stocks.ts` 這張表（40 檔，含假現價），結果才可重現；手動在 app 裡看到的是證交所真實收盤價，數字會不一樣。
清單順序就是選擇器空白時的「熱門股票」順序（接證交所後也沿用這個順序排最前面）。常用的幾檔：

| 代號 | 名稱 | 假現價 |
|---|---|---|
| 2330 | 台積電 | 520 |
| 2317 | 鴻海 | 180 |
| 2454 | 聯發科 | 1200 |
| 2303 | 聯電 | 48 |
| 0050 | 元大台灣50 | 180 |
| 2603 | 長榮 | 200 |
