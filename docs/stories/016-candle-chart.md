# Story 016：股價走勢圖與買入點（含 P2-09 買在高點還是低點）

**身為** 剛開始投資、看不太懂 K 線的人
**我想要** 算完盈虧後，先看到一句白話告訴我「買在高點還是低點」，再看這檔股票的走勢、我的成本和買入點
**以便** 檢討自己的進場時機，也知道現在離成本還有多遠

## 設計理由（ui-ux-pro-max 檢查過）

- **結論放第一位**：新手要的是答案，不是圖。卡片頂端先給一句話＋「高檔／中段／低檔」標籤＋刻度條，圖是佐證。刻度條三段都用中性灰：P2-09 要求只陳述事實，紅綠會暗示好壞。
- **預設折線、K 棒是進階選項**：設計資料庫對 K 線的建議是「非金融背景的使用者不適用，改用折線」。1 年約 240 根 K 棒在手機上每根只剩 1px，折線反而清楚。想看開高低的人一鍵切換，選擇會記住。
- **均線預設關**：第一次看圖不要一次塞四條線。兩條均線用不同顏色**加**實線／虛線區分，不靠顏色單獨傳達。
- **賺賠區**：成本線上下鋪很淡的紅／綠底（台股漲紅跌綠），角落直接寫「↑ 高於成本＝賺」「↓ 低於成本＝賠」，不用圖例也看得懂。
- **買入點改成圓點放在「買入價」的高度**：舊版 ▲ 在 K 棒下方，看不出買在多少錢；現在點的位置就是成本，跟成本線對得上。
- **點圖看某一天＋左右箭頭**：圖表的觸控 tooltip 對不方便精準點的人不友善，所以另外給 48pt 高的前後按鈕（無障礙替代方案）。按住拖曳時手指一放開就把捲動還給畫面，不會卡住上下捲。
- **第一次說明可跳過、可再打開**：設計資料庫 Onboarding 原則「不要強迫看完教學」。
- **錯誤講白話＋技術細節**：同學回報「K 線載入失敗」時看不出原因；現在分成斷網／次數用完／維護中／都沒回應，技術細節可選取複製。

## 規格對照與待 PO 確認

| P2-09 規格 | 這版做法 | 備註 |
|---|---|---|
| 比較區間 3 個月／6 個月／**1 年（預設）**／3 年／自訂 | 1 個月／3 個月／6 個月／**1 年（預設）** | 期間切換同時控制「圖顯示近 N 個月」與「跟買入日前 N 個月比較」。**多了 1 個月、少了 3 年與自訂**：1 個月是這次需求要的；3 年、自訂要抓更多資料，留給持股頁做。**待 PO 確認** |
| 用淺色帶在 K 線圖上標高檔區、低檔區 | 改成結論下方的「低檔／中段／高檔」刻度條 | 圖顯示的是「近 N 個月到今天」，比較區間是「買入日前 N 個月」，兩段時間常常不重疊，把色帶畫在圖上會誤導；圖上已經有賺賠區兩種底色，再加色帶新手分不清。**待 PO 確認** |
| 入口：單一持股頁的每筆買入交易 | 目前在計算頁的單檔結果下方 | 持股頁（P2）做好後同一張卡可以直接搬過去 |
| 拍照匯入的期初持股要註明「買入日為匯入日期」 | 未做 | 計算頁的買入日期都是使用者自己填的，沒有這種情況；持股頁接上時再加 |
| 上市未滿所選區間 | 資料第一天比區間起點晚超過 14 天，就當作上市未滿 | 用資料推斷，不另外查上市日 |
| 除權息資料拿不到 | 用未還原價格計算，並在註明裡寫出來 | 規格沒寫，選「照樣給結論但講清楚」 |

## 實作備忘

- 資料：`src/hooks/usePriceHistory.ts`。要的月份由 `fetchMonths` 算：圖上近 N 個月再往前多 1 個月（20 日均線暖身），加上買入日前 N 個月那一段；兩段不相連時中間不抓。FinMind 不管幾個月都是一個請求，快取按月存。
- 計算都在 domain：`src/domain/buyPosition.ts`（P2-09 百分位，整數比判斷 80%／20% 邊界，還原基準是買入日）、`src/domain/candles.ts`（座標、折線、均線、點擊換算、成本太遠時貼邊）。畫面 `src/ui/CandleChart.tsx` 只照著畫，`src/ui/PriceHistoryCard.tsx` 組卡片，`src/ui/ChartGuide.tsx` 是說明。
- 偏好存在 AsyncStorage `cspo.chartPrefs.v1`（期間、折線／K 棒、均線、看過說明沒），`src/hooks/useChartPrefs.ts`。
- 畫圖沿用 `react-native-svg`，沒加新的原生套件（常見 K 線套件依賴 reanimated／gesture-handler，Android 打包已排除）。觸控用 RN 內建的 responder。
- **iPhone「K 線載入失敗」**：舊版的 K 線只走證交所（網頁版經 `/twse-day` 代理，手機直接打 `www.twse.com.tw`）。原因沒能在 iPhone 上重現；可能是 iOS 連證交所網站被擋或憑證問題（未證實）。現在主來源換成 FinMind，失敗時畫面的「技術細節」會列出每個來源的錯誤（Safari 斷網是 `TypeError: Load failed`），下次有人遇到請截圖技術細節。
- `fallbackSource` 全部失敗時，訊息改成列出每個來源的原因；`monthlyCandleSource` 的錯誤訊息改成帶來源名稱（「證交所載入失敗」「櫃買中心載入失敗」）。
