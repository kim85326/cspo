# Story 002：用代號、公司名稱或清單選股票

**身為** 不一定記得代號的人
**我想要** 打代號、打公司名稱、或直接從清單點選
**以便** 不用先去查代號

## 驗收條件

股票清單與現價以 [docs/glossary.md](../glossary.md) 的假價表為準。

```gherkin
Scenario: 直接打代號
  Given 我在「股票代號或名稱」輸入 2330
  When 我填好買入價與數量並按下「計算」
  Then 結果卡顯示「台積電（2330）」

Scenario: 打完整公司名稱
  Given 我在「股票代號或名稱」輸入 台積電
  When 我填好買入價與數量並按下「計算」
  Then 結果卡顯示「台積電（2330）」

Scenario: 打部分名稱後從清單選
  Given 我在「股票代號或名稱」輸入 聯
  Then 清單出現「2303 聯電」與「2454 聯發科」
  When 我點「聯發科」
  Then 欄位顯示「聯發科（2454）」，清單收起

Scenario: 欄位空白時直接選
  Given 「股票代號或名稱」是空的
  When 我點進欄位
  Then 出現「熱門股票」清單，第一檔是 2330 台積電
  When 我點「鴻海」
  Then 欄位顯示「鴻海（2317）」

Scenario: 多檔符合又沒選
  Given 我輸入 聯 但沒有從清單點選
  When 我按下「計算」
  Then 欄位下方提示「有多檔符合，請從清單選擇一檔」

Scenario: 清除重選
  Given 欄位顯示「台積電（2330）」
  When 我按欄位右邊的 ✕
  Then 欄位清空，可以重新輸入

Scenario: 全形數字也能找
  Given 我輸入 ２３３０
  When 我按下「計算」
  Then 結果卡顯示「台積電（2330）」
```
