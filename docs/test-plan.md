# 手動測試清單

自動化測試已經覆蓋計算邏輯與主要流程，手動測試專注在機器不好驗的事。
每個迭代發版後，測試同學用 Expo Go 跑一輪，結果記在下方表格。

## 怎麼拿到最新版

1. 手機安裝 Expo Go（App Store / Play 商店搜尋 Expo Go）。
2. 跟工程同學的電腦連同一個 Wi-Fi。
3. 用 Expo Go 掃工程同學終端機上的 QR code。
4. 之後程式有更新，畫面會自動重新載入。

## 回報 bug 的格式

開一個 GitHub Issue，照這個格式：

「版本」請貼 app 最底部的版本資訊（點開後複製），工程同學才知道你跑的是哪個 APK、有沒有收到 OTA 更新、還是 Expo Go／網頁版。複製不了的話，長按詳細資訊的文字選取，或直接截圖。

```
版本：（app 最底部的版本資訊：點一下展開 → 按「複製版本資訊」→ 貼在這裡）
手機：iPhone 15 / iOS 18（或 Android 機型與版本）
步驟：
1.
2.
預期：
實際：
截圖：
```

## 截圖匯入（Story 005）

需要工程同學的電腦先設定好 `.env` 的 `ANTHROPIC_API_KEY`，並用 `npx expo start --tunnel` 開 dev server；手機上的 app 會把截圖送到那台電腦辨識。
辨識是 AI 做的，**每次都要對照原始截圖人工核對**：股票、買入價、數量三個欄位都要看。

| # | 檢查項目 | iPhone | Android | 備註 |
|---|---|---|---|---|
| S1 | 第一次按「從截圖匯入」→「從相簿選」，手機跳出相簿權限詢問；允許後能選到截圖 | | | iOS「只選部分照片」也要能用 |
| S2 | 第一次選「拍照」，手機跳出相機權限詢問；允許後能拍照並送出辨識 | | | 拍螢幕時請對焦、避免反光 |
| S3 | 拒絕相簿（或相機）權限後再按：出現「沒有相簿權限…」提示，app 不當掉；到手機設定開啟後再試能用 | | | |
| S4 | 用自己券商 app 的持股截圖匯入：每一檔的股票、買入價、數量都和截圖一致；「張」有換算成股 | | | 把對錯的欄位記在 Issue，附截圖 |

## AI 解讀（Story 017）

需要工程同學的電腦先設定好 `backend/.env`（`ANTHROPIC_API_KEY`、`INSIGHT_ACCESS_TOKEN`）並執行 `npm run backend:tunnel`（ngrok），app 端設好開關、存取碼與 ngrok 網址（Expo Go／網頁版用 `.env.local`，APK 用 EAS 環境變數＋OTA；見 [architecture.md](architecture.md) 第 7 節「AI 解讀後端：給別人連進來」）。
解讀是 AI 寫的，**每次都要對照結果卡的數字核對**，並注意有沒有「投資建議」的語氣。

| # | 檢查項目 | iPhone | Android | 網頁版 | 備註 |
|---|---|---|---|---|---|
| I1 | 開關關閉（APK、一般 Expo Go）：算完看不到「AI 解讀」按鈕，畫面跟之前一樣 | | | | |
| I2 | 單檔：算完按「AI 解讀」，顯示「AI 解讀中…」且不能連按；幾秒內出現總結、2～4 點觀察、風險提醒、「僅為數據解讀，不構成投資建議」 | | | | 超過 30 秒請回報 |
| I3 | 解讀裡的金額、報酬率、股票名稱都跟結果卡一致，沒有出現結果卡以外的數字或新聞 | | | | 對錯的句子記在 Issue，附截圖 |
| I4 | 多檔比較：解讀有提到表現最好與最差的那檔，合計報酬率正確 | | | | |
| I5 | 解讀裡沒有「建議」「應該」「買進」「賣出」「加碼」「減碼」「停損」「目標價」，也沒有「可以考慮多買」之類換句話說的操作建議 | | | | 看到請整段截圖回報 |
| I6 | 關掉電腦的 `npm run backend:tunnel` 再按：顯示「連不上 AI 解讀服務…」與「重試 AI 解讀」，盈虧結果還在；重開後端後按重試能成功 | | | | |
| I7 | 一分鐘內連按超過 5 次（每次等結果出來再按）：顯示「使用太頻繁，請 N 秒後再試」，等一下再按能成功 | | | | |
| I8 | 改數字重新「計算」：舊的解讀卡消失，出現「AI 解讀」按鈕 | | | | |
| I9 | 手機關掉 Wi-Fi、用行動網路：瀏覽器開 `https://<ngrok 網址>/health` 看到 `{"ok":true,...}`；APK 按「AI 解讀」能看到解讀卡 | | | | 工程同學跑 `npm run backend:tunnel` 時 |
| I10 | 工程同學 Ctrl+C 關掉 tunnel 後再按：顯示「連不上 AI 解讀服務：提供服務的電腦可能還沒開…」；重開後按重試能成功（網址不變，不用重裝 app） | | | | |
