# 手動測試清單

自動化測試已經覆蓋計算邏輯與主要流程，手動測試專注在機器不好驗的事。
每個迭代發版後，測試同學用 Expo Go 跑一輪，結果記在下方表格。

## 怎麼拿到最新版

1. 手機安裝 Expo Go（App Store / Play 商店搜尋 Expo Go）。
2. 跟工程同學的電腦連同一個 Wi-Fi。
3. 用 Expo Go 掃工程同學終端機上的 QR code。
4. 之後程式有更新，畫面會自動重新載入。

## 回報 bug 的格式

開一個 GitHub Issue，照這個格式：

```
手機：iPhone 15 / iOS 18（或 Android 機型與版本）
步驟：
1.
2.
預期：
實際：
截圖：
```

## 第二迭代檢查清單：真實行情（證交所）

app 的現價來自證交所 OpenAPI 的「每日收盤行情」，是前一個交易日的收盤價（交易日 15:00 後更新）。
對照網站：https://www.twse.com.tw/zh/trading/historical/stock-day-all.html

| # | 檢查項目 | iPhone | Android | 備註 |
|---|---|---|---|---|
| R1 | 真機上輸入 2330，結果卡的「現價」和證交所網站當日收盤價一致，不是假價 520 | | | |
| R2 | 結果卡標題旁顯示「收盤價 yyyy/mm/dd」，日期是最近一個交易日 | | | |
| R3 | 選擇器空白時「熱門股票」第一檔仍是 2330 台積電；打「台泥」能找到 1101（第一迭代清單裡沒有的股票） | | | |
| R4 | 開 app 後第一次點股票欄位，清單還沒載好時看到「股票清單載入中…」，載好後變成「熱門股票」 | | | |
| R5 | 開飛航模式再開 app：點股票欄位、按「計算」都看到「行情載入失敗，請檢查網路後重試」，不會當掉 | | | |
| R6 | 關掉飛航模式後直接再按「計算」，不用重開 app 就能算出結果 | | | |
| R7 | 當天沒成交或停牌的股票（例如 00625K）查不到，顯示「找不到這檔股票」 | | | |
